# Cara Menggunakan Aplikasi Menu Masakan
# 1. Di Halaman Utama terdapat 2 pliihan di bagian bottom bar yaitu menu category (default halaman) dan search
# 2. Jika ingin mencari makanan klik tombol search dan masukkan kata kunci masakan / makanan yang dicari
# 3. jika ingin memilih kategori makanan secara langsung bisa menscroll kemudian menklik kategori makanan yang dipilih
# 4. Setelah kategori di klik akan muncul makanan apa saja yang ada di list dan bisa dipilih dengan cara di klik makanan yang akan dipilih
# 5. Ketika di klik detail makanan akan muncul dan menjelaskan makanan yang dipilih
